Muat Naik Laman Web

Panduan GitHub Pages 'Danish Kalori'

Ikuti 4 langkah mudah ini untuk melancarkan laman web diet anda secara percuma supaya boleh dibuka di telefon bimbit anda bila-bila masa!

1

Daftar Akaun GitHub & Simpan Fail

1. Pergi ke github.com dan buat akaun.
2. Simpan kod sumber ini sebagai fail index.html.
3. Pastikan gambar 1000413470.png berada dalam folder yang sama!

2

Cipta Repositori (New Repository)

1. Klik pada butang **"+"** di GitHub dan pilih **New repository**.
2. Letakkan nama repositori: danish-kalori.
3. Tetapkan kepada **Public** dan tekan **Create repository**.

3

Muat Naik Fail

1. Klik pautan **uploading an existing file**.
2. Muat naik fail index.html & gambar logo anda.
3. Klik butang hijau **Commit changes**.

4

Aktifkan GitHub Pages

1. Masuk ke **Settings** > **Pages**.
2. Di bawah *Branch*, pilih **main** (atau master) dan tekan **Save**.
3. Laman web anda sedia digunakan secara dalam talian!
